# Hospital Management System

## 📌 Description
This is a Hospital Management System built using HTML, CSS, and Flask. It allows patients to register, login, and book appointments, while doctors can manage and view appointments.

## 🚀 Features
- Patient Login/Register
- Doctor Login
- Book Appointment
- View Appointment List

## 🛠️ Tech Stack
- Frontend: HTML, CSS
- Backend: Flask (Python)

## ▶️ How to Run
1. Install requirements:
   pip install -r requirements.txt
2. Run app:
   python app.py
3. Open browser:
   http://127.0.0.1:5000
